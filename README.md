## Getting Started Playbook

Fit the back buttons you intend to use, connect the Edge with a USB data cable, and identify it in the utility. Choose **Create Profile**, name the layout, and pick an unused shortcut. In **Button Assignments**, map one back button to Cross or another action you can recognize easily, then select **Apply**. In **Stick Sensitivity/Deadzone**, move the stick slowly from rest in **Test Your Controller**, change only one setting at a time, and select **Apply** before leaving the panel and **Done** to finish.

Close the editor, keep the USB connection, and start a session in Sony’s PS Remote Play client. Hold **Fn** and press your chosen face button; with light feedback enabled, Circle, Cross, and Square produce two, three, and four flashes respectively. Verify the back button with a known menu action and compare small camera movements in a repeatable scene. Press **Fn + Triangle** and repeat both checks on Default without changing the game settings.

## Practical Scenarios

Scenario A - Thumb stays on the stick: Assign Cross to a back button and check that it selects the same harmless menu option as the face button.  
Scenario B - Small camera turns: Compare a Precise right-stick curve with Default in the same quiet scene.  
Scenario C - Input at rest: Increase the deadzone only enough to stop unwanted registered movement and check that deliberate small movements still work.  
Scenario D - Wrong shortcut: Turn on profile-switch feedback and compare the observed flash count with the intended face button.

Install issues? If only the streaming client appears in Start, install the separate configuration utility from Sony’s support page.  
Performance problems? If the local stick test looks normal but both streamed profiles feel delayed, compare a wired network session before editing another curve.  
Edition differences? The utility needs no unlock key, while the separate streaming client requires your console's PlayStation account.  
Compatibility? When editing controls is unavailable, check that the connected pad is a DualSense Edge and use USB when moving to the Windows streaming client.
